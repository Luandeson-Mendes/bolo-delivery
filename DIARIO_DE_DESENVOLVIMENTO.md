Registro 01 — Criação do projeto

Data: 25–26 de outubro de 2026

Objetivo

Criar a estrutura inicial do aplicativo móvel de delivery de bolos.

O que foi realizado

- Criação do projeto "bolo-delivery" utilizando o Expo.
- Instalação das dependências iniciais pelo npm.
- Verificação das dependências React, React Native e Expo.
- Inicialização do servidor de desenvolvimento com "npx expo start".
- Abertura do aplicativo no Android utilizando o Expo Go.

Tecnologias e recursos utilizados

- Node.js e npm.
- React e React Native.
- Expo e Expo Go.
- Visual Studio Code e terminal Linux.

Utilização de inteligência artificial

O ChatGPT foi utilizado como ferramenta de apoio para orientar a criação do projeto, explicar a função das dependências, sugerir comandos de terminal e ajudar a diagnosticar possíveis problemas durante a configuração.

Os comandos foram executados no ambiente local, e o aplicativo foi aberto no celular para verificar o funcionamento inicial.

Resultado

O projeto Expo foi criado e executado no dispositivo Android.

Pendências

- Organizar a estrutura definitiva de arquivos.
- Implementar as telas e funcionalidades exigidas pela atividade.
- Investigar os avisos de dependências, quando necessário.

Registro 02 — Primeiros experimentos com a interface

Data: 26 de outubro de 2026

Objetivo

Começar a desenvolver a interface do aplicativo e experimentar a organização dos elementos visuais.

O que foi realizado

- Criação e edição de componentes de interface.
- Utilização de elementos como "View", "Text", "ScrollView" e "TouchableOpacity".
- Definição de estilos com "StyleSheet.create()".
- Experimentação de botões e de uma estrutura inicial de navegação entre telas.

Tecnologias e conceitos utilizados

- Componentes funcionais em React Native.
- JSX.
- Estilização por meio de "StyleSheet".
- Eventos de toque com "TouchableOpacity".
- Estado local com "useState" em uma proposta inicial de interface.

Utilização de inteligência artificial

O ChatGPT foi utilizado para sugerir exemplos de interface, explicar componentes React Native e orientar a conexão entre telas. Também foi utilizado para ajudar a identificar um possível erro de sintaxe relacionado ao uso de vírgula em um valor decimal de JavaScript.

As sugestões foram utilizadas como apoio ao desenvolvimento. Os trechos de código precisam ser revisados, compreendidos e adaptados pelo estudante antes de serem considerados parte definitiva do aplicativo.

Resultado

Foram realizados experimentos com a tela inicial e com uma proposta de formulário de login. O desenvolvimento ainda está em andamento, e não há confirmação de que todas as alterações mais recentes estejam funcionando corretamente.

Pendências

- Verificar e corrigir os possíveis erros na implementação atual.
- Definir a interface final de acordo com o tema de delivery de bolos.
- Implementar e testar o cardápio, a pesquisa, o carrinho e a finalização do pedido.
- Organizar a estrutura definitiva de arquivos e componentes.
- Investigar possíveis problemas de integração com outras tecnologias ou serviços.
